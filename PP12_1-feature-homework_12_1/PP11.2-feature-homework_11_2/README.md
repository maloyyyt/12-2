# Виджет для банковских операций
## Описание:
Данный виджет показывает несколько последних успешных банковских операций клиента.
## Установка:
Клонируйте репозиторий:
```
https://github.com/maloyyyt/PP10-1
```
## Использование

Модуль `processing` содержит функции `filter_by_state` и `sort_by_date`.
### filter_by_state

Функция filter_by_state принимает список словарей и возвращает новый список, содержащий только те словари, у которых ключ state соответствует указанному значению.

**Параметры:**

*   Список словарей с данными о банковских операциях. Каждый словарь должен содержать ключ state.
*   Значение ключа state для фильтрации (по умолчанию 'EXECUTED').

**Возвращает:**

*   Новый список словарей, содержащий только те, у которых ключ state соответствует указанному значению.
### sort_by_date

Функция sort_by_date принимает список словарей и возвращает новый список, отсортированный по дате.

**Параметры:**

*   Список словарей с данными о банковских операциях. Каждый словарь должен содержать ключ date.
*   Порядок сортировки

**Возвращает:**

*   Новый список, отсортированный по дате.

Модуль `generators` содержит функции `filter_by_currency`, `transaction_descriptions` и `card_number_generator`.
Этот модуль предоставляет набор функций для обработки данных о транзакциях и банковских картах.
### filter_by_currency

Функция filter_by_currency принимает на вход список словарей, представляющих транзакции.

**Параметры:**

*  Список словарей, где каждый словарь представляет транзакцию и содержит ключ 'currency'.

**Возвращает:**

*  Итератор, содержащий словари транзакций, соответствующих указанной валюте.
### transaction_descriptions

Функция transaction_descriptions принимает список словарей с транзакциями и возвращает описание каждой операции по очереди.

**Параметры:**

*   Список словарей, где каждый словарь представляет транзакцию. 

**Возвращает:**

*  Итератор, генерирующий описания транзакций в виде строк.
### card_number_generator
Функция card_number_generator выдает номера банковских карт в формате XXXX XXXX XXXX XXXX.

**Параметры:**

*  start: Начальный номер карты (включительно).
*  stop: Конечный номер карты (не включительно).

**Возвращает:**

*  Итератор, генерирующий номера карт в виде целых чисел.
